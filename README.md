# Chheak Lyheng Portfolio

Plain HTML, CSS, and JavaScript portfolio website.

## Run locally

```bash
npm install
npm run dev
```

## Publish on GitHub Pages

1. Create a GitHub repository named `portfolio`.
2. Upload these files to the repository:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `package.json`
   - `package-lock.json`
   - `.gitignore`
   - `README.md`
3. In GitHub, open `Settings` > `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Choose the `main` branch and `/root` folder.
6. Your site URL will be:

```text
https://chheaklyheng.github.io/portfolio/
```
